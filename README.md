# To-Do-List
Код по курсовой по дисциплине "Веб-разработка"
Страницы:
1. Страница домашняя с двумя кнопками: "Войти в приложение", "Зарегистрироваться"
2. Страница регистрации
3. Страница авторизации
4. Профиль пользователя
5. Страница пользователя с возможностью создания задачи
6. Форма создания задачи
7. Страница деталей задачи
8. Список существующих задач пользователя
9. Список расписания выполнения задач
10. Для администратора: Список всех пользователей
11.  Для администратора: Список всех задач


Пользовательские сценарии: «Как [роль], я хочу [действие], чтобы [цель]»:
1.	Зарегистрированный пользователь:
   1.1. Как зарегистрированный пользователь, я хочу получить расписание выполнения своих задач, чтобы понимать как планировать мой день.
  	1.2. Как зарегистрированный пользователь, я хочу видеть на странице просмотра задачи возможность изменить/добавить дедлайн к задаче, чтобы понимать сколько времени у меня есть на неё.
  	1.3. Как зарегистрированный пользователь, я хочу видеть на странице просмотра задачи возможность изменить статус задачи, чтобы понимать нужно ли мне поспешить с выполнением данной задачи или её пока можно отложить.
  	1.4. Как зарегистрированный пользователь, я хочу видеть на странице пользователя свою продуктивность выполнения задач.
2.	Гость:
   2.1. Как гость, я хочу удобно регистрироваться в приложении, чтобы не тратить на это большое количество времени
  	2.2.	Как гость, я хочу после авторизации перейти на страницу своего профиля, чтобы убедиться в том, что я зарегистрировался.
  	2.3. Как гость, я хочу, чтобы страница просмотра одной задачи была достаточно понятной, чтобы не тратить времени на изучение интерфейса.
   2.4. Как гость, я хочу иметь возможность перейти с главной страницы на страницу регистрации, чтобы зарегистрироваться в приложении 
3. Администратор:
   3.1. Как администратор приложения, я хочу видеть список всех пользователей, чтобы понимать какое количество человек пользуется приложением.
   3.2. Как администратор, я хочу видеть список всех задач, чтобы понимать насколько приложение удобно пользователям и регулировать его в случае необходимости.
   3.3. Как администратор, я хочу иметь возможность удалять пользователя, чтобы Поддерживать порядок в системе при наличии неактивных аккаунтов.
   3.4. Как администратор, я хочу иметь возможность удалять задачи, Поддерживать качество контента в системе.
   3.5. Как администратор, я хочу иметь возможность добавлять новых пользователей через административный интерфейс, чтобы Быстро добавлять пользователей без необходимости регистрации через публичную форму.
